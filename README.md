# Mahira's Birthday Surprise 🎀

This is a mobile-friendly birthday website made with HTML, CSS, and JavaScript.

## Project files

- `index.html` — page content and screens
- `style.css` — pink theme, layout, animations, responsive styling
- `script.js` — YES/NO flow, countdown, image matching game, gift reveal, navigation
- `photos/` — put the six photos here

## Add Mahira's photos

Put six pictures you have permission to share into the `photos` folder and name them exactly:

- `mahira1.jpg`
- `mahira2.jpg`
- `mahira3.jpg`
- `mahira4.jpg`
- `mahira5.jpg`
- `mahira6.jpg`

If your images are PNG or WEBP, either convert them to JPG or edit the corresponding image filename in `index.html`.

## Test the website

Open `index.html` in a web browser. Test the YES and NO buttons, countdown, picture matching game, gift box, gallery, and birthday message. The matching game uses emoji picture cards, so a young child does not need to read a riddle.

## Publish free using GitHub Pages

1. Sign in or create a free account at https://github.com/.
2. Create a new repository called `mahira-birthday`.
3. Choose **Public**, then create the repository.
4. Upload `index.html`, `style.css`, and `script.js` to the repository's top/root level.
5. Upload the `photos` folder containing the six pictures. The final paths should be `photos/mahira1.jpg` through `photos/mahira6.jpg`.
6. Open **Settings → Pages** in the repository.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Select branch `main` and folder `/(root)`, then save.
9. Wait for GitHub Pages to publish. Your URL will look like `https://YOUR-USERNAME.github.io/mahira-birthday/`. Replace `YOUR-USERNAME` with your GitHub username. This is an example URL, not a live published site.
10. Open the link on your phone and test every step.

Official guide: https://docs.github.com/en/pages/quickstart

## Customizing

- Change the words in `index.html`.
- Change colors and design in `style.css`.
- Change the game or button behavior in `script.js`.
- After editing files on GitHub, commit your changes and wait for Pages to redeploy.

## Privacy

GitHub Pages websites are public. Anyone who has the URL may be able to view the site, so use only photos you have permission to share and avoid sensitive pictures. A paid domain is not required.
